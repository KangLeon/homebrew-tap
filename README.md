# KangLeon Homebrew tap

Install [MellowClean](https://github.com/KangLeon/MellowClean), a small native macOS cleaner:

```sh
brew install KangLeon/tap/mellowclean
mellowclean
```

Requires macOS 13+ and Swift 5.9+ / Xcode Command Line Tools 15+.
Builds from a versioned source archive verified with SHA-256.

```sh
brew upgrade mellowclean
brew uninstall mellowclean
```
